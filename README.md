# 婚礼电子请柬实时设计器

一个可在浏览器中直接使用的婚礼请柬编辑器。支持实时修改请柬内容、上传新人照片，并将最终请柬导出为图片。

## 运行项目

项目不需要安装依赖或执行构建命令，可以直接双击 `index.html` 打开。

也可以在项目目录启动本地静态服务器：

```powershell
python -m http.server 8765
```

启动后访问：

```text
http://127.0.0.1:8765/
```

## 编辑请柬

页面左侧是内容编辑区，右侧会实时显示最终效果。

可以编辑以下内容：

- 邀请对象
- 受邀人
- 称谓和副标题
- 新郎、新娘姓名
- 婚礼日期和农历日期
- 婚礼地点
- 邀请寄语
- 请柬落款

切换“邀请对象”时，系统会自动填充适合朋友、父母亲友、长辈或同事的邀请文案。自动生成后仍可继续手动修改。

## 上传照片

1. 点击“上传新人照片”。
2. 选择 20MB 以内的 JPG、PNG 或 WebP 图片。
3. 照片会自动裁切并填满左侧相框。
4. 点击“移除照片，恢复留白相框”可以清除当前照片。

为获得更好的展示效果，建议使用人物位于画面中央、清晰度较高的竖版或接近竖版的照片。

## 导出请柬

支持以下图片格式：

- WebP：清晰且文件较小，适合发送到微信或其他社交平台。
- JPEG：兼容性较好，适合一般分享和打印预览。
- PNG：无损导出，文件较大，适合保存原图。

选择图片格式和质量后，点击右上角“导出请柬”。浏览器会下载一张 `1255 × 1080` 的成品图片。

PNG 为无损格式，因此图片质量选项不会生效。

## 恢复默认内容

点击右上角“恢复默认”，可以恢复默认的朋友邀请文案、新人姓名占位、日期、地点和落款。

已上传的照片不会被此操作删除。如需清除照片，请单独点击“移除照片，恢复留白相框”。

## 项目文件

- `index.html`：页面结构和编辑表单。
- `styles.css`：页面布局与界面样式。
- `app.js`：请柬绘制、内容预设、照片处理和图片导出功能。

## 浏览器要求

建议使用较新版本的 Chrome、Edge、Firefox 或 Safari。浏览器需要支持 HTML Canvas、文件上传和图片下载功能。
